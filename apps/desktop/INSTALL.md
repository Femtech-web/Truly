# Install Truly for macOS

This direct-download build supports Apple Silicon and Intel Macs running macOS 14.2 or newer.

1. Open the `Truly-0.1.0-macOS-universal.dmg` file.
2. Drag **Truly** into the **Applications** folder.
3. Open **Applications**, Control-click **Truly**, choose **Open**, then confirm **Open**.
4. If macOS still blocks the first launch, open **System Settings → Privacy & Security**, find the Truly notice, and choose **Open Anyway**. Do not disable Gatekeeper globally.
5. Use the Truly menu-bar icon to open **Settings → Connection**, then pair this Mac from **Devices** in the Truly Mini App inside Nimiq Pay.
6. Allow **Screen Recording** when you choose to share a screen. Microphone and Speech Recognition are optional and used only for Voice mode.

This free distribution is ad-hoc signed and is not Apple-notarized, so macOS displays an unverified-developer warning on first launch. Truly connects to `https://app.usetruly.site`; it never asks for wallet recovery words or private keys.

Product guide: <https://www.usetruly.site/docs>
